One funny single-line one-star review from a house cat about its human,
written by `main.py` to `/output/entry.txt` for the make.fun competition
"Make the AI Judge Laugh: Cat Reviews Its Human".

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: it writes one fixed line (1–200 characters,
single line, non-blank) and nothing else. No randomness, no network.
